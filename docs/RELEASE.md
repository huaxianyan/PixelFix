# 发布说明规范

发布说明按仓库通用规范执行：新功能与问题修复分节、标题只用版本号、产物名为 `PixelFix-<版本>.apk`。本文只补充本仓库特有的要求。

## 每条修复必须写清影响的系统版本

本仓库的修复都是针对具体系统版本的症状，系统更新后问题可能自行消失。发布说明里每条修复都要回答三件事：

- 问题出现在哪个系统版本；
- 这一版在哪个系统版本上验证过；
- 装到别的系统版本上会怎样。

写法示例：

```markdown
## 问题修复

- **屏保锁屏**：退出时钟屏保后设备再次锁定，只能输入 PIN。问题出现在 Android 17
  `CP3A.261005.005`，本版在该构建上验证；其他构建上该修复会自动停用，不影响其余功能。
```

不要写「修复若干问题」「提升稳定性」这类看不出影响面的说法。

## 版本号

- 标签与 `versionName` 一致，形如 `v0.3.0`。
- 新增修复或修复行为变化时提升次版本号；只改文档不改版本。
- 每个版本同步更新 [兼容范围](COMPATIBILITY.md) 表。

## 产物

- 只发布一个包：`PixelFix-<版本>.apk`，同时附 `.sha256`。
- 构建信息表记录版本、版本号、min / target SDK、包名、签名证书 SHA-256、源码提交与产物哈希。
